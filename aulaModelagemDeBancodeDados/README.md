# Sistema de Gestão Escolar – EduManage
Projeto SQL – Criação e Manipulação de Dados

Este repositório contém os scripts SQL desenvolvidos para o projeto EduManage, conforme solicitado.
Inclui criação de tabelas (DDL), scripts de povoamento (INSERT), consultas (SELECT), updates e deletes (DML),
além de documentação e um documento Word com o projeto lógico.

Como usar:
1. Clone ou baixe este repositório.
2. Execute `01_create_tables.sql` em MySQL Workbench ou PGAdmin.
3. Execute `02_insert_data.sql`.
4. Teste consultas em `03_select_queries.sql`.
5. Rode `04_update.sql` e `05_delete.sql` conforme necessário.
